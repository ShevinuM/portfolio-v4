What if you could search a whale call? MobyGrep listens to live underwater microphones (hydrophones), detects whale calls in the audio, turns each call into a numeric fingerprint, and makes the calls searchable. This is an open source search engine covering all the distinct whale calls.

Built with Python, FastAPI, Redis Streams, Postgres + pgvector and Docker Compose.

The source is at [github.com/ShevinuM/moby-grep](https://github.com/ShevinuM/moby-grep).
